# Sinais e Sistemas — Experimento 01

Gerar uma senoide de 50 Hz amostrada a 1000 Hz durante 1 segundo e calcular a transformada discreta de Fourier via FFT real (`rfft`).

O espectro unilateral de amplitude deve apresentar um pico próximo de 50 Hz, com amplitude aproximadamente igual a 1.

Execute a partir da raiz do repositório:

```bash
python sinais-e-sistemas/src/senoide_fft.py
```
