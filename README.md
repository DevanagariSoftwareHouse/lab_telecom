# Lab Telecom

Laboratórios reproduzíveis de Engenharia de Telecomunicações em Python.

## Laboratório 01 — Sinais e Sistemas

Experimento: gerar uma senoide, calcular sua FFT e visualizar o sinal no tempo e seu espectro.

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python sinais-e-sistemas/src/senoide_fft.py
```

O gráfico será salvo em `sinais-e-sistemas/resultados/senoide_fft.png`.
